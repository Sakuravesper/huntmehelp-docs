# HUNTME Documentation

This repository contains public documentation, scripts, and onboarding notes for HUNTME.

Main site: [huntme.help](https://huntme.help)

## What this repository is for

The goal of this repository is to make HUNTME documentation easier to access and understand.
It collects practical materials for onboarding, workflow reference, and script structure.

## What you will find here

- onboarding notes
- workflow overviews
- script templates
- qualification guidance
- FAQ and reference materials

## Structure

### Documentation
Clear explanations of the partner workflow, key steps, and operational notes.

### Scripts
Reference scripts and templates used in the HUNTME partner process.

### FAQ
Common questions and short answers for faster orientation.

## Purpose

This repository is meant to support the public documentation layer for HUNTME.
If you are looking for the main website, use [huntme.help](https://huntme.help).
